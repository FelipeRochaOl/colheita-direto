# 10 · Gestão do produtor (ERP de bolso)

Uso principal pelo WhatsApp (voz/foto) e pelo app; o web espelha.

## MVP
- [x] Registro de colheita (cultura, quantidade, data, foto) criado automaticamente pelo lote — **Pronto quando:** cada lote gera entrada de colheita
- [x] Estoque por lote (disponível, reservado, vendido, doado, perdido) — **Pronto quando:** saldo bate com pedidos e destinos
- [x] Receitas automáticas a partir das vendas (repasse Asaas) — **Pronto quando:** extrato do produtor confere com o Asaas

## v1
- [ ] Despesas por voz/foto de nota ("gastei 200 reais de adubo") via agente — **Pronto quando:** despesa categorizada corretamente em ≥ 90% dos testes _(implementado, falta verificar)_
- [ ] Fluxo de caixa simples e resultado por safra/cultura — **Pronto quando:** produtor vê lucro por cultura _(implementado, falta verificar)_
- [ ] Calendário de plantio/colheita por cultura — **Pronto quando:** lembretes enviados
- [ ] Diagnóstico de pragas por foto + histórico por talhão — **Pronto quando:** diagnóstico fica no histórico
- [ ] Alertas de clima (previsão de chuva/geada na janela de colheita) — **Pronto quando:** alerta enviado ≥ 24 h antes
- [ ] Relatório mensal por WhatsApp (vendas, perdas, comparação com mês anterior) — **Pronto quando:** enviado automaticamente
- [ ] Documentos: CAF, notas, contratos PNAE — **Pronto quando:** upload e validade com lembrete

## Escala
- [ ] Multiusuário (família, técnico da cooperativa) com permissões — **Pronto quando:** técnico acessa produtores da cooperativa
- [ ] Histórico como base de score para crédito rural (com consentimento) — **Pronto quando:** exportação para parceiro financeiro
